Important Notice for Upgrading from Older Builds (v1.x or Early Alpha)

Starting with v2.2.0, Wafeer uses official release signing keys. If Android prompts "App not installed as package appears to be invalid", please export a quick CSV backup of your expenses, uninstall the older test build, and install the official signed release.
